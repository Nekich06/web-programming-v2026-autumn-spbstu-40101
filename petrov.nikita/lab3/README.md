# Лабораторная работа 3

## Задание

Вариант 14.

Реализуйте функцию `countOccurrences(arr)`, которая возвращает объект с
количеством вхождений каждого элемента.

## Реализация

Функция `countOccurrences(arr)` перебирает массив элементов `arr` и возвращает
объект, где ключи - строковые представления элементов, а значения - количество
их вхождений.

Создается пустой объект `result`, затем в цикле `for...of` перебираются все
элементы переданного массива или итерируемого объекта, для каждого элемента
создается строковый ключ через `String(item)`, а соответствующее ключу значение
в `result` увеличивается на единицу, используя `nullish coalescing`.

Функция корректно работает с пустыми массивами и итерируемыми объектами. На
разреженных массивах "дырки" обходятся как `undefined` и попадают в результат
отдельным ключом `"undefined"`. Передача `null` или `undefined` вместо аргумента
не выбрасывает ошибку - возвращается пустой объект.

## Запуск

Импортируйте именованный export `countOccurrences` из файла `solution.js` как ES
module.
