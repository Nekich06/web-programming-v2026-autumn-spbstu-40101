# Лабораторная работа 2

## Задание

Вариант 14.

Написать функцию, которая преобразует цвет из HEX-формата в RGB-формат
(например, "#FF0000" -> "rgb(255, 0, 0)").

## Реализация

Функция `hexToRgb` принимает строку с цветом в HEX-формате и возвращает строку
вида `rgb(r, g, b)`.

В процессе обработки строки функция убирает пробелы и `#`, разворачивает
сокращённую запись (`#f00` -> `ff0000`), проверяет формат, разбивает строку на 3
пары `RR`, `GG`, `BB` и парсит их как HEX-числа.

Если после нормализации строка не соответствует формату `RRGGBB`, функция
бросает `Error('Invalid HEX color')`.

## Запуск

Импортируйте именованный export `hexToRgb` из файла `solution.js` как ES module.
