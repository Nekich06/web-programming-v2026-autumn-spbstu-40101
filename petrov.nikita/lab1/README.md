# Лабораторная работа 1

## Задание

Вариант 14.

Создать горизонтальное навигационное меню, где активный элемент выделяется
другим цветом. Для реализации можно использовать `<nav>`, `<ul>`, `<li>`, и
`<a>`. Один из пунктов меню должен быть активным (например, при помощи
class="active").

## Реализация

Меню реализовано через тег `<nav>` с классом main-nav. Внутри него лежит
маркированный список `<ul>`, а каждый пункт — это `<li>` с вложенной ссылкой
`<a>`. У первой ссылки («Главная») стоит класс active, который и помечает её как
активный пункт.

Горизонтальное расположение пунктов достигается за счёт `display: flex` у списка
`<ul>`.

Ссылки внутри пунктов сделаны блочными (`display: block`) с внутренними
отступами padding. Это нужно, чтобы кликабельной была вся область пункта, а не
только текст.

## Запуск

Откройте `index.html` в браузере.
